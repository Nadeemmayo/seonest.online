# seonest.online

SEONest website (GitHub Pages). Shared styles in `assets/css/site.css`, scripts in `assets/js/site.js`, self-hosted fonts and icons in `assets/`. Blog posts are managed via `/admin` (Decap CMS) and rendered with `_layouts/post.html`.

## Team photos

- Manager photo: upload Sidra's photo as `assets/img/sidra-shoukat.jpg` (portrait, about 720×900). It appears automatically on the About page, the home page team strip and the Contact page; until then a "Photo coming soon" placeholder with her initials is shown.
- Sidra's social links (Snapchat, TikTok, LinkedIn, WhatsApp) are placeholders (`href="#"`) in `about.html`, `index.html` — search for `s-sc`, `s-tt`, `s-li`, `s-wa`.
